# جاينك — رفع على السيرفر

## بثلاث خطوات

**١.** ارفع هذا المجلد كاملاً على السيرفر (لوحة التحكّم أو FTP أو أي وسيلة).

**٢.** من طرفية السيرفر، ادخل المجلد ونفّذ:

```bash
sudo bash setup.sh
```

**٣.** يطبع لك العنوان في النهاية. افتحه من أي جوّال.

## ماذا يفعل السكربت

- ينسخ الملفات إلى `/opt/jaynak`
- ينشئ مستخدم خدمة لا يملك صلاحيات زائدة
- يركّب خدمة `systemd` تعمل تلقائياً **وتنجو من إعادة تشغيل السيرفر**
- يولّد `SESSION_SECRET` **مرّة واحدة ويثبته**
- يفتح المنفذ 8787 في جدار الحماية إن وُجد `ufw`

## أوامر تحتاجها

```bash
sudo systemctl status jaynak      # الحالة
sudo journalctl -u jaynak -f      # السجلّ الحيّ
sudo systemctl restart jaynak     # إعادة تشغيل
```

## رمز التحقّق

بلا مزوّد رسائل، الرمز **يُطبع في السجلّ** ولا يُرسل:

```bash
sudo journalctl -u jaynak -f | grep "الرمز"
```

للإرسال الحقيقي: أضف مفاتيح المزوّد في `/opt/jaynak/.env` (الأسماء في
`.env.example`) ثم `sudo systemctl restart jaynak`.

**⚠️ لا تضع `ALLOW_DEV_CODE=1` أبداً على سيرفر عام** — يُعيد رمز التحقّق
في جسم الرد، أي أن أي شخص يدخل بأي رقم، ومنه رقمك فتُفتح لوحة الإدارة.

## ⚠️ ما ينقص قبل مستخدمين حقيقيين

**١. HTTPS.** هذا `http`: رموز الدخول وصور البطاقات تمرّ **نصّاً مكشوفاً**
على الإنترنت. لا ترفع بطاقة هوية حقيقية قبل التشفير.

الحلّ: اسم نطاق (~٤ ر.ع. سنوياً) + Caddy:

```bash
sudo apt install -y caddy
# /etc/caddy/Caddyfile:
#   jaynak.com {
#       reverse_proxy 127.0.0.1:8787
#   }
sudo systemctl reload caddy
```

Caddy يجلب الشهادة ويجدّدها وحده.

**٢. المخزن ملف JSON** لا قاعدة بيانات — يصلح لعشرات الطلبات يومياً لا
آلاف. استبدله بـPostgreSQL قبل التوسّع.

**٣. نسخ احتياطي** لـ`/opt/jaynak/data/` — فيه الطلبات والحسابات
والمستندات.
